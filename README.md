# HR Attrition Dashboard – Power BI & SQL

## Project Overview
This project analyzes employee attrition using SQL Server and Power BI. 
The dashboard provides insights into employee demographics, job satisfaction, 
salary, overtime, education, job roles, and other factors affecting employee attrition.

## Tools & Technologies
- SQL Server
- Power BI
- DAX
- Power Query
- Excel / CSV

## Key Analysis
- Employee Attrition Rate
- Attrition by Department
- Attrition by Job Role
- Attrition by Education
- Attrition by Overtime
- Attrition by Business Travel
- Attrition by Salary Hike
- Attrition by Years in Current Role
- Employee Job Satisfaction
- Employee Job Level
- Gender Analysis

## Dashboard
The Power BI dashboard provides an interactive view of HR metrics and helps identify patterns and factors related to employee attrition.

## Files Included
- `HR_.pbix` – Power BI dashboard file
- `HR_Attrition_dataset.csv` – Dataset used for analysis
- `HR_Dashboard.png` – Dashboard preview
